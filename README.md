# fund-research-agent

基金产品识别、底层基金归并、官方资料/月报搜索、可追溯用户评论数据管线和痛点/卖点分析工具。

## 功能

1. 读取图片、Excel、CSV、PDF、TXT/Markdown 附件，抽取基金产品代码、晨星代码、ISIN、中英文基金名称。
2. 归并同一底层基金的不同份额，统计底层基金数量、份额数量、份额代码和名称。
3. 深度搜索每只底层基金的最新 factsheet、月报、KFS、产品资料概要等资料，抓取正文摘录、识别资料日期、按官方来源/资料类型/新鲜度打分，标记最新候选资料。
4. 补充基金产品主数据，结构化 KID/factsheet/月报字段，覆盖官方费率、风险等级、底层持仓、回撤、流动性、配置和收益风险字段。
5. 在基金列表内按同类产品做对比，分析每只基金的产品特色、差异化或罕见投资策略，并保留资料链接证据。
6. 搜索小红书、微博、抖音近半年针对每家基金公司的公开结果，或读取用户导出的评论 CSV，并将评论标准化为 `FundCompanyMention`。
7. 对评论做脱敏、稳定哈希、去重、近半年自然月窗口标记、风险标记和人工复核队列，按基金公司分析投资者痛点和内容卖点。
8. 配置“基金分析大师”能力层，穿透产品机制、映射投资者痛点、生成下月卖点雷达和反证审计。
9. 输出 Excel 研究报告。

> 说明：小红书、微博、抖音的评论区通常需要登录且有反爬限制。本项目不绕过登录、验证码、付费墙或平台访问限制；推荐使用平台授权接口、合规第三方数据服务，或用户自行导出的评论 CSV。原始评论、`.env`、业务输入和输出报告不应提交到公开仓库。

## 安装

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
```

图片 OCR 依赖较重；如只读取 Excel/CSV，可以先不安装 `paddleocr` / `paddlepaddle`。

## 配置

复制环境变量模板：

```bash
cp .env.example .env
```

填写搜索和大模型相关 API Key：

```bash
SERPAPI_KEY=your_key
TAVILY_API_KEY=your_key
OPENAI_API_KEY=your_key
```

没有搜索 API Key 也可以运行本地附件读取、基金识别、底层归并、统计和用户导出评论分析。设置 `FETCH_DOCUMENT_TEXT=0` 可只保留搜索结果，不抓取资料正文。

近半年窗口按自然月计算，默认 `SOCIAL_RECENT_MONTHS=6`。例如运行日为 `2026-06-06` 时，社媒窗口为 `2025-12-06` 至 `2026-06-06`，报告审计表会记录窗口和时区 `Asia/Shanghai`。

## 使用

读取 Excel：

```bash
python main.py data/fund_list.xlsx
```

读取多张图片：

```bash
python main.py image1.jpeg image2.jpeg image3.jpeg image4.jpeg
```

只做本地识别和归并，不做联网搜索：

```bash
python main.py data/fund_list.xlsx --no-doc-search --no-social-search
```

接入已导出的社媒评论 CSV：

```bash
python main.py data/fund_list.xlsx --social-comments-csv data/social_comments.csv
```

读取 PDF/TXT 附件：

```bash
python main.py attachment.pdf notes.txt --no-social-search
```

运行测试：

```bash
python -m unittest discover -s tests -v
```

输出文件默认在：

```text
output/fund_research_report.xlsx
```

## 社媒评论 CSV 格式

```csv
fund_company,platform,source_type,user_text,publish_time,like_count,url,title
摩根资产管理,小红书,social,这个基金分红挺高但净值也跌了，不知道是不是亏本金,2026-03-12,23,https://...,摩根基金讨论
汇丰资产管理,微博,social,亚洲债券最近是不是受降息预期影响比较大,2026-04-03,8,https://...,汇丰基金评论
```

必要列为 `platform`、`user_text`，以及 `fund_company` / `company` / `product_code` 至少一列。推荐提供：

| 字段 | 说明 |
|---|---|
| `fund_company` | 基金公司中文名，例如 `摩根资产管理`、`惠理集团` |
| `platform` | 小红书、微博、抖音、天天基金、支付宝基金、知乎、雪球等 |
| `source_type` | `social`、`video_comment`、`forum`、`qna`、`complaint_portal`、`app_store`、`news_comment` 等 |
| `user_text` | 用户评论正文或公开摘要 |
| `publish_time` | 发布时间，用于自然月近半年窗口判断 |
| `url` / `link` | 原文链接，用于证据链和哈希去重 |
| `like_count` | 可选互动数据 |
| `title` | 可选页面标题 |

系统会将公开搜索结果标记为 `search_result`，这类记录默认进入人工复核队列，因为搜索摘要不一定等同于真实用户评论。没有日期的记录会保留并标记 `low_confidence_date` 和 `manual_review`。

## 社媒来源策略

| 来源 | 用法 |
|---|---|
| 小红书 | 公开笔记、图文页、可合规导出的评论 |
| 微博 | 公开微博、话题页、评论摘要 |
| 抖音 | 公开视频、搜索页、公开视频评论线索 |
| 基金销售 App | 天天基金、支付宝基金、银行 App 等公开评论或导出数据 |
| 投诉/问答/社区 | 黑猫投诉、知乎、雪球、贴吧等公开页面 |

## 评论数据链路

```text
搜索/导出 -> 标准化 FundCompanyMention -> PII 脱敏 -> 稳定哈希 id_hash
-> duplicate_of 去重 -> 情感/方面/意图标签 -> 风险标记 -> 审计摘要/人工复核 -> 基金公司痛点卖点
```

痛点标签覆盖：亏损/回撤、分红误解、净值波动、汇率/人民币对冲、高收益债信用风险、港股/亚洲市场波动、赎回/申购/费率、平台客服/信息披露。

卖点标签覆盖：高派息/现金流、稳健配置、降息受益、亚洲增长、低估值修复、多资产分散、人民币对冲、品牌信任。

## 基金分析大师能力

项目内置 `fund-mechanism-analyzer`、`fund-peer-performance-underwriter`、`fund-peer-comparator`、`fund-market-narrative-radar`、`fund-investor-pain-mapper`、`fund-evidence-auditor`、`fund-cost-fee-analyzer`、`fund-report-strategist` 八类能力配置。

核心判断链为：

```text
产品清单 -> 底层基金归并 -> 官方资料/月报穿透 -> 产品机制识别
-> 历史业绩/费用/同类证据缺口标记 -> 投资者痛点映射
-> 下月卖点雷达 -> 反证审计 -> 合规传播建议
```

当前版本会先基于已有官方资料、基金类别和用户评论输出机制穿透、痛点映射、下月卖点候选和反证审计；历史净值、费用、完整持仓、外部同类基金池、派息历史和实时市场指标若未接入，会在报告中明确标记为缺失证据，避免把营销词当成投研事实。

## 基金产品主数据

`基金产品主数据` 会按底层基金归并官方资料和份额信息，并从 KID / factsheet / monthly report 的正文摘要中抽取以下字段：

- 官方资料链接：最新 factsheet、KID / 产品资料概要、月报标题、链接和日期。
- 产品属性：投资目标、资产类别、基金分类、基础货币、份额特征、派息政策、人民币/币种对冲、基准。
- 官方费率：管理费、经常性开支/ongoing charges、申购费、赎回费、转换费、费率摘要。
- 风险等级：SRI / SRRI / 官方风险等级、风险来源和风险摘要。
- 底层持仓和配置：前十大持仓、资产配置、行业配置、地区配置。
- 债券和收益字段：久期、平均信用评级、到期收益率、派息率。
- 回撤和流动性：最大回撤、交易频率、结算周期、赎回流动性。
- 数据质量：主数据完整度分数、缺失字段、证据链接。

无法从官方资料中结构化识别的字段不会被猜测，会进入 `missing_master_fields`，供后续人工复核或接入净值/费率/持仓数据源补齐。

## 报告 Sheet

| Sheet | 内容 |
|---|---|
| 基金清单摘要 | 附件中识别出的基金产品数量、底层基金数量、基金名称、产品代码和 ISIN 汇总 |
| 全部份额 | 每个基金份额代码、晨星代码、ISIN、中英文名、归属底层基金 |
| 底层基金统计 | 每只底层基金、份额数量、对应产品代码、ISIN、名称集合 |
| 官方资料搜索结果 | 每只底层基金搜索到的 factsheet / 月报 / KFS 链接、来源质量、资料日期、最新候选、正文摘录 |
| 官方资料分析 | 产品分类、最新资料证据、产品特色、罕见策略、列表内同类对比 |
| 基金产品主数据 | 官方费率、风险等级、底层持仓、回撤、流动性、KID/factsheet/月报结构化字段和缺失字段 |
| 基金公司社媒搜索结果 | 小红书 / 微博 / 抖音按基金公司搜索的公开结果或用户导出评论，含近半年标记 |
| 基金公司评论标准记录 | 标准化后的 `FundCompanyMention`，含 `id_hash`、脱敏文本、方面、意图、风险标记和重复关系 |
| 基金公司痛点卖点 | 每家基金公司的有效评论数、去重后评论数、近半年命中率、平台分布、低置信样本数、痛点和卖点 |
| 采集审计摘要 | 窗口、时区、原始行数、标准化记录数、去重记录数、低置信比例、平台/来源类型命中数 |
| 人工复核队列 | 搜索摘要、缺少日期、疑似不相关、低置信记录等需要人工确认的证据链接 |
| 大师Skill配置 | 基金分析大师所需能力、优先级、输入数据和输出结果 |
| 产品机制穿透 | 每只底层基金的收益来源、风险来源、适配痛点、隐藏风险和缺失证据 |
| 痛点机制映射 | 投资者痛点与产品机制的映射、当前产品适配度和不可直接宣传项 |
| 下月卖点雷达 | 可用于下月传播的卖点候选、触发条件、需补证据、风险披露和置信度 |
| 反证审计 | 支持证据、缺失证据、反证风险、置信度和审计结论 |

## 实现边界

- 官方资料搜索使用 SerpAPI 和 Tavily；同时配置时会合并去重。系统会优先识别官方/基金经理域名，但最终资料有效性仍应由研究员复核。
- 最新资料通过标题、链接、摘要和抓取正文中的日期识别，并结合资料类型和来源质量评分；无法识别日期的资料不会被强行当作最新。
- 社媒搜索只使用公开网页结果和用户提供的导出评论，不绕过平台登录、验证码或反爬机制。搜索和分析维度为基金公司；若需要真实评论区全量样本，应接入平台授权接口或合规第三方数据服务。
- 评论分析不做个人画像；系统会脱敏手机号、邮箱和长数字标识，并把低置信样本输出到人工复核队列。
